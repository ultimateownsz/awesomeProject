# Game Mechanics Graph

Explore game mechanics in an interactive graph visualization. Each node represents a game mechanic loaded from JSONCanvas files, with connections showing relationships between mechanics.

## How to Use

- **Click and drag** nodes to reposition them
- **Hover** over nodes to see mechanic details
- **Click** on nodes to view full mechanic documentation
- **Zoom** in and out using mouse wheel or pinch gestures

## Mechanic Types

- **Movement**: Jump, dash, slide mechanics
- **Combat**: Attack, block, parry mechanics  
- **Traversal**: Climbing, swimming, flying mechanics
