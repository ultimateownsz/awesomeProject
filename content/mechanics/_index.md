# Game Mechanics Toolkit

Explore game mechanics as interactive nodes. Each mechanic is represented as a JSONCanvas file with visual descriptions, references, and connections to related mechanics.

## Features

- **Visual Documentation**: GIFs, images, and rich descriptions
- **Connected Mechanics**: See how mechanics relate to each other
- **Use Cases**: Understand when to apply each mechanic
- **References**: Links to examples and analysis
