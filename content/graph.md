# Graph View

Explore the awesome list categories in an interactive graph visualization. Each node represents a category, and connections show relationships between categories.

## How to Use

- **Click and drag** nodes to reposition them
- **Hover** over nodes to see category details
- **Click** on nodes to navigate to that category
- **Zoom** in and out using mouse wheel or pinch gestures
